# FizzBuzz カスタマイズ

範囲や判定基準（割る数）を画面から自由に変更・再計算できる、テーブル形式の FizzBuzz Web アプリケーションです。

## 特徴

- **範囲と割る数を自由に設定**:
  - **開始数値** と **終了数値** を指定可能（初期値: 1 〜 50）
  - **Fizz の割る数**（初期値: 3）および **Buzz の割る数**（初期値: 5）を変更可能
- **「再計算する」ボタン**: 入力した条件で瞬時に判定し、テーブルとサマリーを再描画。
- **「初期値に戻す」ボタン**: ワンクリックでデフォルト設定（1〜50, 3, 5）にリセット。
- **入力バリデーション**:
  - ゼロ除算防止（割る数は 1 以上の整数）
  - 開始数値 ≦ 終了数値 の整合性チェック
  - パフォーマンス保護（1度に計算できる件数は最大 1,000 件まで）
- **見やすいテーブル表示 & 色分けバッジ**:
  - **Fizz**: 青色バッジ（例: `Fizz (3の倍数)`）
  - **Buzz**: オレンジ色バッジ（例: `Buzz (5の倍数)`）
  - **FizzBuzz**: 紫色バッジ（例: `FizzBuzz (3 & 5の倍数)`）
  - **通常**: グレー色バッジ
- **集計サマリー**: 全件数、および各判定ごとの件数をリアルタイムに集計表示。
- **単一ファイル構成**: 外部ライブラリ不要で、`index.html` 1ファイルで動作。

## 使い方

1. 本リポジトリをクローンまたはダウンロードします。
2. `index.html` をお好みの Web ブラウザ（Chrome、Edge、Safari、Firefox 等）で開きます。
3. 画面上部の入力フォームで、開始数値・終了数値・Fizzの割る数・Buzzの割る数を設定します。
4. **「再計算する」** ボタンをクリックすると、設定した条件でテーブルが再計算・更新されます。
5. 初期状態に戻したい場合は **「初期値に戻す」** ボタンをクリックします。

```bash
# 例: ブラウザで開く（Windows）
start index.html
```
