# FizzBuzz カスタマイズ

範囲や判定基準（割る数）を画面から自由に変更・再計算できる、テーブル形式の FizzBuzz Web アプリケーションです。

## 特徴

- **範囲と割る数を自由に設定**:
  - **開始数値** と **終了数値** を指定可能（初期値: 1 〜 50）
  - **Fizz の割る数**（初期値: 3）および **Buzz の割る数**（初期値: 5）を変更可能
- **「再計算する」ボタン**: 入力した条件で瞬時に判定し、テーブルと集計サマリーを再描画。
- **「初期値に戻す」ボタン**: ワンクリックでデフォルト設定（1〜50, 3, 5）にリセット。
- **入力バリデーション & 安全設計**:
  - ゼロ除算防止（割る数は 1 以上の整数）
  - 開始数値 ≦ 終了数値 の整合性チェック
  - パフォーマンス保護（1度に計算できる件数は最大 1,000 件まで）
  - 不正入力時のエラーメッセージ表示
- **見やすいテーブル表示 & 動的バッジ**:
  - 各行に判定結果とバッジを表示
  - バッジテキストも設定値に連動（例: `Fizz (4の倍数)`、`Buzz (7の倍数)`、`FizzBuzz (4 & 7の倍数)`）
- **集計サマリーバー**: 全件数、および各判定ごとの件数（Fizz、Buzz、FizzBuzz、通常）を自動集計して表示。
- **単一ファイル構成**: 外部ライブラリ・CSSフレームワーク不要。`index.html` 1ファイルのみで動作します。

## 入力項目の仕様

| 項目名 | 初期値 | 入力条件 | 説明 |
| :--- | :--- | :--- | :--- |
| **開始数値** | `1` | 整数 | 計算を開始する数値 |
| **終了数値** | `50` | 整数（開始数値以上） | 計算を終了する数値（最大1,000件） |
| **Fizz の割る数** | `3` | 1 以上の整数 | Fizz と判定する基準値 |
| **Buzz の割る数** | `5` | 1 以上の整数 | Buzz と判定する基準値 |

## 判定ルール

1. **FizzBuzz**: 数値が「Fizzの割る数」と「Buzzの割る数」の**両方で割り切れる**場合（公倍数）
2. **Fizz**: 数値が「Fizzの割る数」で割り切れる場合
3. **Buzz**: 数値が「Buzzの割る数」で割り切れる場合
4. **通常**: 上記のいずれにも該当しない場合（数値をそのまま表示）

## 使い方

1. 本リポジトリをクローンまたはダウンロードします。
2. `index.html` をお好みの Web ブラウザ（Chrome、Edge、Safari、Firefox 等）で開きます。
3. 画面上部の入力フォームで、開始数値・終了数値・Fizzの割る数・Buzzの割る数を設定します。
4. **「再計算する」** ボタンをクリックすると、設定した条件でテーブルが再計算・更新されます。
5. 初期状態に戻したい場合は **「初期値に戻す」** ボタンをクリックします。

```bash
# ブラウザで開く例（Windows）
start index.html
```
