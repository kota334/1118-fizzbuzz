# FizzBuzz (1〜50)

1から50までの範囲で FizzBuzz の判定結果をテーブル（表）形式で表示するシンプルな Web アプリケーションです。

## 特徴

- **見やすいテーブル表示**: 1から50までの数値、判定結果、種別バッジを整理された表形式で確認できます。
- **視覚的な色分け**:
  - **Fizz (3の倍数)**: 青色バッジ
  - **Buzz (5の倍数)**: オレンジ色バッジ
  - **FizzBuzz (15の倍数)**: 紫色バッジ
  - **通常**: グレー色バッジ
- **集計サマリー**: テーブル上部に全件・各判定ごとの件数（全件: 50件 / Fizz: 13件 / Buzz: 7件 / FizzBuzz: 3件 / 通常: 27件）を表示します。
- **依存関係なし（単一ファイル）**: 外部ライブラリやフレームワークを使わず、HTML/CSS/JavaScript を `index.html` 1ファイルにまとめています。

## FizzBuzz の判定ルール

| 条件 | 表示内容 | 例 |
| :--- | :--- | :--- |
| 15 の倍数（3 と 5 の公倍数） | `FizzBuzz` | 15, 30, 45 |
| 3 の倍数 | `Fizz` | 3, 6, 9 ... |
| 5 の倍数 | `Buzz` | 5, 10, 20 ... |
| 上記以外 | 数値そのもの | 1, 2, 4 ... |

## 使い方

特別なサーバーやビルド環境は不要です。

1. 本リポジトリをクローンまたはダウンロードします。
2. `index.html` をお好みの Web ブラウザ（Chrome、Edge、Safari、Firefox 等）で開くだけで閲覧できます。

```bash
# 例: ブラウザで開く（環境に応じたコマンド）
start index.html
```
